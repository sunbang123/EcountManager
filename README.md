# Ecount Manager

영업팀이 전화 응대 중 Ecount ERP의 고객, 판매, 채권, 품목, 가격 및 재고 정보를 빠르게 확인할 수 있도록 만든 C# 데스크톱 통합 뷰어입니다.

현재 버전은 **공식 Open API 기반 읽기 전용 뷰어 + 로컬 메모 친구 v0.3.0**입니다. 주문 등록과 전표 수정은 Ecount 웹페이지에서 수행하며, 앱에는 공식적으로 조회 가능한 품목·재고 정보와 로컬 업무 보조 메모만 표시합니다.

## 현재 구현

- 테스트/운영 서버 선택, Zone 자동조회 및 로그인 세션 발급
- 연결 시에는 데이터를 조회하지 않고 정확한 품목코드를 검색할 때만 API 호출
- 검색한 품목코드 1건의 품목·전체 재고·창고별 재고 조회
- 검색 버튼 또는 Enter를 누를 때만 조회하며 타이핑만으로는 API를 호출하지 않음
- 검색한 품목을 로컬 화면에 누적하고 품목코드·품목명·출고단가만 간결하게 표시
- 검색된 품목의 Ecount 그룹코드(`CLASS_CD`)로 그룹 설정 목록과 필터 자동 구성
- 앱 실행 시 Ecount Manager와 메모 친구들을 각각 켜고 끄는 이동식 리모컨 표시
- 메모 친구의 아이콘 축소 기능을 제거하고 리모컨 또는 `Ctrl+2`로 전체 창을 표시/숨김
- 리모컨이 다른 창 뒤에 있어도 `Ctrl+1`로 Ecount Manager를, `Ctrl+2`로 메모 친구를 각각 표시/숨김
- 리모컨을 따라 움직이는 별도 전원형 `화면 가리지 않기` 버튼 또는 `Ctrl+3`으로 작업 창을 완전히 투명하고 클릭이 통과되는 상태로 전환하고 다시 눌러 복원
- `화면 가리지 않기` 버튼을 드래그하면 리모컨도 함께 이동하고, 리모컨을 드래그하면 버튼이 함께 이동
- 리모컨은 투명 모드에서도 항상 위 상태를 유지하므로 복원 즉시 다른 창 위에 표시
- `화면 가리지 않기` 버튼은 투명 모드에서도 100% 불투명도와 항상 위 상태를 유지
- Ecount Manager도 메모 친구와 같은 투명 지원 커스텀 창으로 구성하고 상단 드래그 바로 이동
- 투명 모드 토글은 불투명한 독립 패널에서 OFF는 주황 발광/빨간 배지, ON은 초록 테두리/배지로 상태를 강하게 구분
- API 인증키를 파일에 저장하지 않는 세션 전용 입력 방식
- 항상 위에 표시되는 메모 친구 위젯과 리모컨 기반 켜기/끄기
- 상담 친구: 상호명, 전화번호, 사업자등록번호, 문의내용 및 수정되지 않는 최초 생성시간 저장
- 상호명과 사업자등록번호 개별 클립보드 복사
- 상담 내용을 `상호명 / 전화번호` 보고 양식으로 클립보드 복사
- 상담 메모 선택 삭제 및 확인창이 있는 전체 초기화
- 복붙 친구: 자주 쓰는 문장 등록, 삭제 및 버튼 복사
- 복붙 문장 속 연속된 백틱 2개를 입력칸으로 변환해 완성 문장 생성
- 업무 친구: 중단한 업무를 짧게 저장하고 완료 체크 시 목록에서 제거

## 실행

```powershell
dotnet run --project .\src\EcountManager\EcountManager.csproj
```

## 구조

- `Models`: Ecount 조회 데이터와 상담·복붙·업무 메모 모델
- `Services`: Ecount Open API 클라이언트와 JSON 기반 로컬 메모 저장소
- `ViewModels`: 검색, 필터, 화면 상태를 관리하는 MVVM 계층
- `MainWindow.xaml`: 공식 API 품목·재고 뷰어
- `RemoteControlWindow.xaml`: 앱 시작 화면이자 두 기능 창의 표시/숨김을 제어하는 이동식 리모컨
- `MemoWidgetWindow.xaml`: 상담·복붙·업무를 아이콘 탭으로 제공하는 데스크톱 메모 위젯
- `SnippetFillWindow.xaml`: 연속된 백틱 2개 위치의 입력값을 받아 완성 문장을 복사하는 창
- `docs/PRODUCTION_PROCESS.md`: 순차 제작 계획과 완료 기준

## 실제 Ecount 연결

1. Ecount의 `Self-Customizing > 정보관리 > API인증키발급`에서 테스트 인증키를 준비합니다.
2. 앱 왼쪽에서 회사코드, 인증키 발급 ID, API 인증키를 입력합니다.
3. 테스트 서버를 선택한 상태로 `Ecount 연결만 하기`를 실행합니다. 이 단계에서는 품목·재고 API를 호출하지 않습니다.
4. 정확한 품목코드를 입력하고 `품목 조회` 또는 Enter를 눌러 해당 품목만 조회합니다.
5. 메뉴별 검증 후 정식 인증키를 발급받으면 테스트 서버 선택을 해제하고 운영 인증키로 연결합니다.

API 인증키는 앱을 종료하면 사라지며 Git 저장소나 설정 파일에 기록되지 않습니다.

## 로컬 메모 저장 위치

메모는 사용자 PC의 `%LocalAppData%\EcountManager`에 JSON 파일로 저장됩니다.

- `consultation-memos.json`: 상담 메모
- `copy-snippets.json`: 복붙 문장
- `work-memos.json`: 진행 중 업무

상담 목록의 `전체 초기화`는 상담 메모만 삭제하며 복붙 문장과 업무 메모에는 영향을 주지 않습니다.
